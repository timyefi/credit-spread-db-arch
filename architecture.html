Chapter 03 · Fetcher Layer

取数层：四引擎与自动降级链

取数层是整个数据库的"供水系统"。四台引擎各自独立，UnifiedFetcher 作为总阀按优先级自动降级——任何一台引擎停摆，管线不断流。

降级边界
AKShare 降级只支持国债 / 国开债基准与 ETF。信用债 YTM（中短票、城投、二永）在 iFinD 与 DM 同时失效时不可用——此时 UnifiedFetcher 会抛出明确异常提示转用 Wind MCP，而非静默返回错误数据。

引擎一：DmFetcher（首选，100% 覆盖）

基于 Dealing Matrix 量化 API，通过收益率曲线接口直接获取各评级各期限 YTM。29 条预置曲线覆盖中短票、企业债、城投、二永、基准、证券公司债、存单；17 个 API 端点覆盖曲线、个券估值、一级发行、基金净值、隐含评级、EDB、交易日历。

方法对应视角输出限流约束
get_yield_curve()视角 1–7DataFrame[curve_term, valuation_date, yield]期限≤5 · 跨度≤1月
get_spread_matrix()视角 1 利差总表dict[CS_* bp]（4评级×3期限）单日调用
get_urban_spread()视角 2 城投dict（5评级利差 vs 国开）单日调用
get_bank_capital_spread()视角 3 二永dict（6曲线利差 + 永续溢价）单日调用
get_primary_issue()视角 8 / 10 一级list[dict] 发行记录（自动翻页）跨度≤30天
get_fund_nav()视角 11 ETFDataFrame[nav, change_pct]代码≤200 · 跨度≤1年
独立调用 · 最小可运行示例（DM）
from fetcher import DmFetcher

dm = DmFetcher()                      # 自动读取 fetcher/config.json 的 dm 凭证
m  = dm.get_spread_matrix("20260717") # 视角1：AAA/AA+/AA/AA- × 1Y/3Y/5Y 利差(bp)
print(m["CS_AAA_3Y"])                # → 例 21.43

curve = dm.get_yield_curve("中短票_AAA", ["1Y","3Y","5Y"],
                           "20260617", "20260717")   # 一个月时序

引擎二：UnifiedFetcher（自动降级总阀）

核心方法 get_yield(indicator, start, end, source="auto")。指标名支持中文别名（"中短票_AAA_3Y"）或直接 M码；_resolve_m_code() 从 ifind_edb_codes.yaml 查表解析，iFinD 失败后按降级链自动切换。

独立调用 · 自动降级示例
from fetcher import UnifiedFetcher

uf = UnifiedFetcher()
uf.status()   # 打印四数据源可用状态

# auto：iFinD HTTP(M码) → AKShare(仅基准) → 抛异常提示转 MCP
y = uf.get_yield("国开债_3Y", "20260617", "20260717")

# 指定源：跳过降级，直连某引擎
y2 = uf.get_yield("中短票_AAA_3Y", "20260617", "20260717", source="dm")

etf = uf.get_etf(["511260"], "20260617", "20260717")  # ETF 需 AKShare

引擎三 / 四：iFinD HTTP 与 AKShare

ifind_fetcher.py 是约 120 行的最小客户端，只封装 edb 与 data_pool 两个端点，只需 requests + token 即可独立运行，无需安装完整 ifind-http-skill。akshare_fetcher.py 完全免费、无需 token，调用失败返回空 DataFrame 而非抛异常，天然适合做兜底。

替换策略
要接入新数据源（如中债登直连），只需新建 xxx_fetcher.py 并实现 get_yield / get_etf 两个方法，再在 unified_fetcher.py 的降级链中注册优先级——知识层与输出层零改动。
Chapter 04 · Knowledge Layer

知识层：契约、M码、阈值与快照

知识层是纯静态文件，不依赖任何运行时。它是整个数据库的"大脑皮层"——取数靠它找 M码，计算靠它定公式，点评靠它判松紧。

data_contract.yaml · 单一事实源

11 视角 × 5 数据源的完整契约。所有利差公式、阈值、M码映射都以此文件为准，Agent 与脚本不得硬编码。

核心公式（契约定义）
# 基准 = 国开债（备选 = 国债）
信用利差 CS = Y_credit(同评级同期限) − Y_国开债(同期限)
期限利差 TS = Y_long − Y_short          # 5Y-1Y / 10Y-1Y / 30Y-10Y
等级利差 RS = Y_lower − Y_higher        # AAA-AA+ / AA+-AA / AA-AA-
品种利差 PS = Y_typeA − Y_typeB         # 二级-普信 / 永续-二级
历史分位数  = Count(CS_hist ≤ CS_now) / N × 100%   # 区间：2022年以来

阈值体系 · 国开债口径

国开债利率天然比国债高约 15–30bp，故国开口径的利差阈值相应更低。所有阈值随信用周期变化，每年检视。

维度偏紧 / 偏贵中性偏宽 / 便宜
AAA 1Y 利差< 15 bp15 ~ 30 bp> 50 bp
AAA 3Y 利差< 20 bp20 ~ 35 bp> 55 bp
AAA 5Y 利差< 25 bp25 ~ 40 bp> 60 bp
二级资本债 AAA- 5Y< 30 bp30 ~ 55 bp> 70 bp
永续溢价（vs 二级）< 5 bp5 ~ 15 bp> 20 bp
10Y AAA 利差< 30 bp30 ~ 50 bp> 50 bp
信用周期评分卡（5 维度）与四阶段策略

评分卡维度：AAA 3Y 分位 · 等级利差 · 一级-二级偏离 · 评级下调 · 违约新增。得分 +3~+5 积极下沉 / 0~+2 中性 / -2~-1 防御 / -5~-3 危机。

四阶段策略：信用扩张（拉久期+下沉）→ 信用平稳（持有+个券）→ 信用收缩（缩短久期→AAA）→ 信用危机（防御→国债）。

AAA 3Y 周期参考：资产荒 20~30bp · 正常 30~50bp · 信用事件冲击 50~80bp · 危机 >80bp。

M码速查 · 踩坑标注

ifind_edb_codes.yaml 收录 380+ 已验证 M码，并标注了真实踩坑记录——例如 M001618024 是 4Y 而非 3Y，中短票_AA+_5Y 应为 M001619336。ifind_edb_codes_extended.yaml 为扩展码（周配额超限后定位、待验证）。

iFinD 已知盲区
二永债 EDB 无 M码 · 永续债收益率不存在 · 行业利差 p04983 仅合计行 · 一级发行利率 p04650 全部 "--" · TLAC / 美元债仅 Wind MCP 可取。这些视角请直接走 DM Quant API。

离线快照 · data_snapshot.json

52 个指标的日度时序（约 50+ 交易日），结构为 {"指标名": [{"d":"日期","v":数值}]}。取数层全部失效时，计算层可直接读快照完成演示与回测。

独立操作 · 直接读快照（零取数）
import json
snap = json.load(open("knowledge/data_snapshot_20260717.json", encoding="utf-8"))
aaa3y = snap["中短票 AAA 3Y"]      # [{d,v}, {d,v}, ...]
cdb3y = snap["国开债 3Y"]
cs = [(a["v"] - b["v"]) * 100 for a, b in zip(aaa3y, cdb3y)]  # 利差 bp
Chapter 05 · Output Layer

输出层：图表引擎、点评模板与看板

输出层把计算结果变成周报可直接粘贴的产物：6 个 matplotlib 图表函数、6 套结构化点评模板、1 个 ECharts 自包含看板。

图表引擎 · chart_credit_spread.py

全局样式 SimHei / 微软雅黑，150dpi，axes.unicode_minus=False。每个函数接收纯数据、返回 fig 并落盘 PNG。

函数图表类型输入特征
chart_cs_matrix()利差热力图df[行=评级, 列=期限]RdYlGn_r · vmin=10 vmax=100
chart_cs_timeseries()多系列利差折线dates + {标签: 值列表}含 40bp 参考线
chart_grade_spread()等级利差折线{"AAA-AA+ 3Y": [...]}多评级对比
chart_cs_percentile()分位数分组柱状df[行=评级, 值=%]20%偏贵 / 80%偏便宜参考线
chart_industry_spread()行业利差横向柱状行业列表 + bp 值>80红 / <30绿 / 中位数线
chart_cs_combo()双轴组合图dates, cs, volume利差折线 + 发行量柱状

输出规范（铁律）
所有产出物写入 output/ 子目录 · 文件名含 _YYYYMMDD 日期后缀 · 历史版本不覆盖 · HTML 必须自包含（inline CSS/JS）· 同一文件不得同时存在于根目录与 output。
